# Watchlist — well-known projects and brands

Names whose bare token is already owned by a strong project or brand, so using
the same word forces a `collision` verdict even when the registry says `free`.
This table grows as each naming search finds a new one.

| Token                                             | What owns it                                                                                      | Why it is a hard collision                    |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------- | --------------------------------------------- |
| `canopy`                                          | Enthought Canopy (Python distribution) + Pinecone Canopy + `github.com/canopy` org                | developer-tool + Python adjacency             |
| `codex`                                           | OpenAI Codex                                                                                      | the word is synonymous with the model         |
| `orchard`                                         | Orchard CMS (8k★)                                                                                 | major open-source platform                    |
| `radix`                                           | Radix UI (19k★)                                                                                   | dominant in the same developer mindshare      |
| `delta`                                           | git packfile term + Delta Airlines + `delta` the git-diff pager                                   | collision with git plumbing itself            |
| `grove`                                           | `nicksenap/grove` (git worktree orchestrator)                                                     | same domain, not just a name squatter         |
| `garden` / `coppice`                              | `garden-rs/garden`, `iamfozzy/coppice`                                                            | git-worktree/multi-repo tools                 |
| `overstory`                                       | `jayminwest/overstory` (AI orchestration)                                                         | collides with a sibling orchestrator's domain |
| `got`                                             | PyPI crawler (dead), `sindresorhus/got` (15k★ HTTP client), crates `got` (Rust git CLI), `go get` | collision on every developer surface          |
| `gud`                                             | `git-gud` ×2 (886★/559★), GUD debugger                                                            | the joke is already taken, twice              |
| `radicle`                                         | `radicle-dev` (P2P decentralized git)                                                             | same conceptual space                         |
| `estuary`                                         | estuary.dev (data-sync tool)                                                                      | sync-adjacent brand                           |
| `aqueduct`                                        | stablekernel/aqueduct (Dart framework)                                                            | strong framework brand                        |
| `orchard` / `trellis` / `willow` / `arbor`        | Orchard CMS / agent-harness Trellis / Nike Willow / react-arborist                                | tree-family taken                             |
| `mangrove`                                        | Mangrove DAO                                                                                      | known brand                                   |
| `tally` / `recon` / `saga` / `logbook` / `unison` | davidfowl/tally, reconftw, redux-saga, zalando/logbook, Unison file-sync                          | record/sync family mined                      |
| `sluice` / `weir` / `freshet` / `runnel`          | registered on PyPI                                                                                | water-mechanism family mined                  |

Rule of thumb that emerges from this table: **the evocative single-word
namespace — tree, water, tide, record, resonance — is largely exhausted.** New
names survive by compounding (`redge-cli`), coining, or the registry-name /
binary-name split, not by finding one more unused poem word.
